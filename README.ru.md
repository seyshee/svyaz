## Установка на Linux amd64

```sh
curl -fL https://github.com/seyshee/svyaz/releases/latest/download/svyaz-linux-amd64 -o svyaz
chmod +x svyaz
./svyaz
```

Откройте <http://127.0.0.1:8080>, создайте администратора и сохраните ключ входа. Данные хранятся в `./svyaz-data/`. Для доступа из интернета после первичной настройки подключите HTTPS-прокси к `127.0.0.1:8080`.
